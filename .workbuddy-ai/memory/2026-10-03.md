### 中文提交信息的坑
Windows Git Bash 下直接 `git commit -m "中文"` 会因编码报错。
解法：加 `-c i18n.logOutputEncoding=UTF-8`，例如
`git -c i18n.logOutputEncoding=UTF-8 commit -q -m "..."`。
已写入 AGENTS.md 供后续参考。
