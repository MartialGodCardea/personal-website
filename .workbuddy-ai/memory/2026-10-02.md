# 2026-10-02

## 个人博客网站（复刻 oniguili.jp）

**目标**：以 <https://www.oniguili.jp/（西村祥子个人站）的日式编辑网格设计语言为蓝本，>  
为王松林（用户本人）开发一个静态个人博客站。内容源：`个人介绍.txt`。

### 交付物

- `site/` — 纯静态站点（HTML/CSS/原生 JS，无框架、无构建步骤），共 19 个页面、1.2 MB。
  - `index.html` 首页：design / journal / notes / prof 四段
  - `profile/index.html` — 经历时间轴 + 擅长什么 8 项
  - `projects/index.html` — 4 个案例（问题/做法/结果 三段式）
  - `notes/` — 索引 + 8 篇详情
  - `journal/` — 索引 + 6 篇详情
- `tools/` — 构建与校验脚本（不参与部署）
  - `build_pages.py` 生成 notes/journal 全部页面
  - `make_placeholders.py` 用 Pillow 生成 13 张占位图
  - `screenshot.py` Chrome headless 截图（含 iframe 移动端模拟）
  - `pngtool.py` 纯标准库 PNG 像素探针

### 设计系统要点（复刻自参考站 style.min.css）

- 5 列 CSS grid：`repeat(5, 1fr)`，`column-gap: 24px`，`--pad-x: 40px`；嵌套用 `subgrid`。
- 固定浮层（logo / 日期 / 导航 / 巨型名牌 / 页脚）统一用 `mix-blend-mode: difference`
  - 近白色 `--ghost:#fafafa`，随下方内容滚动自动反相。
- 竖排文字 `writing-mode: vertical-rl`：logo `SONGLIN`、日期 `( Oct. 2nd, 2026 )`、中文导航。
- 巨型背景字 `.name_en` 340px / `opacity:.05`；巨型名牌 `.name_ja` 72px，  
  行高 `3fr 5fr 186px`，王/松/林 逐字右下错落。
- 视口节奏用 `svh`：`#main_contents { margin: 56svh 40px 40svh }`。
- 图片灰阶 → 彩色：`filter: grayscale(100%)` → `grayscale(0%)`，  
  由 `IntersectionObserver`（`rootMargin: 0 0 -70% 0`）触发 `.is-active`。
- 开场动效：首屏字母闪烁（打乱索引 + setInterval 100ms）→ 导航 100ms 逐项 `.is-visible`  
  → 其余淡入；`sessionStorage.hasVisited` 保证只播一次，并有 5s 兜底移除 `.is-loading`。

### 字体（自托管 woff2）

Bodoni Moda（正体 + 斜体，latin 子集）+ Noto Serif SC（`text=` 子集，仅含「王松林」三字，2.3 KB）。

### 踩坑与修复

1. `@font-face` 子集：Noto Serif SC 只打包名牌用到的三个字，体积从 MB 级降到 2.3 KB。
2. 桌面端简介栏塌成「一行一个字」：参考站的 `width:48%` 假设外层是 5 列 grid，  
   而我给 `.prof a` 设了 `grid-column: 4/6` 使其只有 2 列，48% 只剩约 85px。  
   → 改用显式 flex（`gap:6%`，图 38% / 文 56%）。
3. 页脚不可见：参考站是浅色文字 + difference 混合，我写成纯黑。→ 补 `mix-blend-mode`。
4. 移动端正文列过窄：`≤834px` 时 `.body` 只有 `grid-column: 1/3`（约 292px）。  
   → 放宽到 `1/5`，`≤500px` 时 `1/6`。
5. 目录式链接（`profile/`）在 `file://` 下失效 → 全站 19 个文件统一改成显式 `index.html`。
6. Chrome on Windows headless 窗口宽度被钳制在约 500px，  
   移动端截图需用定宽 iframe 模拟（`screenshot.py` 的 frame 模式）。
7. 截图出现整片空白 / 黑色块 —— 经 DOM 探针排除 CSS/JS 问题，判定为本机  
   headless 合成层栅格化缺陷；改用「压缩节奏 CSS + 超高视口」整页截图绕过。

### 校验结果（本次收尾）

- 272 条站内引用、19 个 HTML，**0 断链**。
- 桌面 1440px / 移动 390px 双端截图逐页确认：首页、简介、案例、笔记索引、  
  笔记详情、日记索引、日记详情均正常。
- 配色数值比对参考站一致（logo 最暗像素 0、巨型字区 242、名牌区 5）。
